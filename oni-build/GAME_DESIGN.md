# 建築鬼ごっこ — 試作 STEP 1

建築 × 高鬼 × 氷鬼 × 鬼ごっこ。昼に資材を集めて建て、夜は鬼から逃げ切る。

- 遊び方: `index.html` を Android スマホのブラウザ(縦画面)で開く。1ファイル完結・外部ライブラリなし。
- PC でも確認可能: WASD/矢印で移動、J=拾う、K=建てる、Q=建築切り替え、L/Space=叩く(鬼は J/Space で攻撃)。

## ゲームの流れ
タイトル → 陣営選択(人/鬼) → (鬼なら)種類選択(肉食動物/モンスター) → 昼フェーズ → 夜フェーズ → 結果

## 人数
- 人 6人、鬼 2匹。プレイヤーが選ばなかった陣営は全員CPU。
- プレイヤーが鬼の場合、CPUの鬼はもう一方の種類になる。

## 昼フェーズ (`DAY_TIME` 秒)
- 箱に触れる(または「拾う」)と開いて木材・石が飛び出す。触れると回収、「拾う」で近くの資材を吸い寄せる。
- 30秒ごとにランダムイベント(画面上部にテロップ)
  - 資材の雨: 指定エリアに箱が降ってくる(エリアは点線の円で表示)
  - 巨大宝箱: どこかに出現(ミニマップで点滅)、開けると資材が大量に出る
- 建築(「建てる」で向いている方向の1マス先。点線枠でプレビュー)
  - 足場: 木材2 / HP4 / 高鬼のセーフ地帯
  - 壁: 石3 / HP8 / 通行をふさぐ
  - 「建てる」長押しで種類切り替え
- 鬼は歩けるが、人に触れても何も起きない・建物も壊せない。
- 力の実(赤い実)を拾うと夜の移動速度 +8%/個(最大3個)。

## 夜フェーズ (`NIGHT_TIME` 秒)
- 画面が暗くなり、自分の陣営のキャラの周りだけ見える。ミニマップにも敵は映らない。
- 鬼は四隅の巣からスタート。
- 鬼に触れられると凍結。頭上に残り秒数。仲間が2秒触れ続けると解凍。`FREEZE_LIMIT` 秒で脱落。
- `MAX_FREEZE_COUNT` 回凍結した人は、次のタッチで即脱落(キャラの下の点が凍結回数)。
- 高鬼: 足場の上の人は肉食動物にタッチされない。同じ足場に5秒いると崩れ始め、2秒後に消える(頭上のゲージで表示)。
- 叩く: 鬼を2秒気絶させる。スタミナ35消費、時間で回復。
- 鬼の攻撃: 肉食動物は建物に1ダメージ、モンスターは5ダメージ(足場1回・壁2回で破壊)。モンスターは足場の上の人にもタッチできる。

## 勝敗
- 鬼: 夜の間に人を全員脱落させれば勝ち。
- 人: 夜の終わりに1人でも脱落していなければ勝ち(凍結中でも脱落前なら生存扱い)。

## 調整用の定数
`index.html` の `<script>` 先頭にまとめてある。

| 定数 | 値 |
| --- | --- |
| DAY_TIME | 90 |
| NIGHT_TIME | 120 |
| FREEZE_LIMIT | 30 |
| MAX_FREEZE_COUNT | 3 |
| HUMAN_COUNT | 6 |
| ONI_COUNT | 2 |

速度・建築コスト・HP・スタミナ・イベント内容なども同じ場所で調整できる。

## 仕様で決めきれていなかった点(試作での判断)
- 「拾う」ボタン: 触れるだけでも回収できるので、近くの箱を開けて周囲の資材を吸い寄せる「まとめ拾い」にした。
- 夜でも建築は可能。
- 鬼の攻撃ボタン: 前方の人がいればタッチ、いなければ前方1マスの建物を攻撃。
- 夜の開始時、鬼は巣(四隅)に戻る(昼に人の近くにいた鬼が即タッチするのを防ぐため)。
