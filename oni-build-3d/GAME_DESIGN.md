# 建築鬼ごっこ 3D — 試作 STEP 1

- `index.html` を Android スマホの横画面で開く。Three.js(r128)を cdnjs から読み込む以外は1ファイル完結。
- PC: WASD 移動 / ←→ カメラ回転 / Space ジャンプ / J 拾う / K 建てる / Q 建築切り替え / L 叩く(鬼は J/L で攻撃)

## 実装メモ(仕様からの判断)
- ジャンプの高さ 1.3 → 高さ1の段差だけ登れる。肉食動物 0.55・モンスター 0.5 なので、鬼はブロックに登れない。
- 「高い場所」= 足元の高さ 0.5 以上。モンスターは高さ 1.05 までタッチできる。
- 鬼の攻撃は、鬼の足元の高さにあるブロック(なければ一番下)を壊す。下のブロックが壊れると上のブロックが落ちる。
- 「建てる」1回目でプレビュー表示、2回目で設置。プレビューは6秒操作がないと消える。
- 資材は多め: 箱130個 × 5個、巨大宝箱50個、資材の雨26箱。初期 木材4・石3。
- CPU の人は昼に階段状の足場(1段→2段→3段)を最大2か所作り、夜は肉食動物が近いと高い場所へ登る。
- ランタンの光は軽さのため、カメラに近い3人分だけ実際の光源にしている(他は光る玉のみ)。
- 木や小屋がカメラとプレイヤーの間に入ると、カメラが近づく。
- 夜の開始時、鬼は四隅の巣に戻る。

# 部屋と鬼の待機ルーム

## 部屋(STEP1は2部屋)
- フィールドを中央の仕切り壁で「🌲森」(西)と「🏭廃工場」(東)に分ける。仕切りには通路が2か所(北寄り・南寄り)。
- 森: 木を多めに配置(見通しが悪い)。小屋2軒・岩が少し。
- 廃工場: 灰色の床。4×4の小部屋が並ぶ迷路状の壁(隙間は2マス)と錆びたタンク。
- 昼は通路を自由に行き来できる(部屋に入るとトースト表示)。通路の上には建築できない。
- 各部屋に入口が2つ(北・南)。

## 鬼の待機ルーム(昼)
- 鬼は昼のあいだフィールドに出ず、待機ルーム画面で「種類」「部屋の投票」「強化」を選ぶ。昼の残り時間を表示。人の建築は見えない。
- 投票の多い部屋に決定、同数ならランダム。選ばなかった項目は夜にランダムで決まる。CPU鬼は部屋と強化をランダムに選ぶ。
- 強化: 移動速度アップ(×1.2) / 破壊力アップ(×2) / 凍結時間延長(その鬼が凍らせた人は解凍に2倍=4秒かかる)。
  - 「凍結時間延長」は、凍結がそのまま長くなると脱落までの時間が延びて鬼が不利になるため、「解凍しにくくなる」と解釈した。
- 鬼を選んだ場合、タイトル後の種類選択画面は出さず、待機ルームで種類を選ぶ。
- プレイヤーがCPU鬼と同じ種類を選ぶと、CPU鬼はもう一方の種類に変わる。
- 力の実(昼に鬼が拾う)は、鬼が昼にフィールドへ出なくなったので廃止し、強化に置き換えた。

## 夜の開始
- 「鬼が◯◯の部屋を選んだ！」とテロップ。
- 通路を赤いゲートで閉じ、選ばれた部屋だけで鬼ごっこ(もう一方の部屋の建物は残るが行けない。ミニマップでも暗く表示)。
- 人は部屋の入口の片方(ランダム)の付近にランダム配置、鬼は反対側の入口から登場。
