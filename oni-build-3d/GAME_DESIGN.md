# 建築鬼ごっこ 3D — 試作 STEP 1

- `index.html` を Android スマホの横画面で開く。Three.js(r128)を cdnjs から読み込む以外は1ファイル完結。
- PC: WASD 移動 / ←→ カメラ回転 / Space ジャンプ / J 拾う / K 建てる / Q 建築切り替え / L 叩く(鬼は J/L で攻撃)

## 実装メモ(仕様からの判断)
- ジャンプの高さ 1.3 → 高さ1の段差だけ登れる。肉食動物 0.55・モンスター 0.5 なので、鬼はブロックに登れない。
- 「高い場所」= 足元の高さ 0.5 以上。モンスターは高さ 1.05 までタッチできる。
- 鬼の攻撃は、鬼の足元の高さにあるブロック(なければ一番下)を壊す。下のブロックが壊れると上のブロックが落ちる。
- 「建てる」1回目でプレビュー表示、2回目で設置。プレビューは6秒操作がないと消える。
- 資材は多め: 箱130個 × 5個、巨大宝箱50個、資材の雨26箱。初期 木材4・石3。
- CPU の人は昼に階段状の足場(1段→2段→3段)を最大2か所作り、夜は肉食動物が近いと高い場所へ登る。
- ランタンの光は軽さのため、カメラに近い3人分だけ実際の光源にしている(他は光る玉のみ)。
- 木や小屋がカメラとプレイヤーの間に入ると、カメラが近づく。
- 夜の開始時、鬼は四隅の巣に戻る。

# 部屋・ラウンド・救援(現在の仕様)

## 定数
NIGHT_COUNT=3 / ROOM_COUNT=2(最大4) / RESCUE_OPEN=30 / HUMAN_ROOM_CAP=4 / ONI_ROOM_CAP=2 / ONI_SPLIT_MIN=3 / ROOM_SELECT_TIME=10 / ONI_ENTER_DELAY=2

## 部屋
- フィールドを縦長の部屋に区切る(仕切り壁2列、通路2か所)。STEP1は「🌲森」「🏭廃工場」。ROOM_COUNT=4にすると「深い森」「倉庫」が加わる。
- 各部屋の北の柵に扉があり、その上に救援ランプがある。
- 昼のあいだ通路は閉じていて、人は自分の部屋の中だけで資材集めと建築をする。

## ラウンドの流れ
部屋選択(10秒) → 昼 → 夜 を NIGHT_COUNT 回くり返す。
- 部屋選択: 早い者勝ち・定員4。満員の部屋はグレー。選ばなかった人は人数が少ない部屋へ自動で入る(=均等に配置)。CPUも人数が少ない部屋を優先。
- 部屋を移った人は資材を持ち越し、建物は前の部屋に残る。2夜目以降の昼は箱が追加で湧く。
- 夜明け: 通路が閉じ、凍結していた人は元に戻り、全員が自分の部屋の集合場所へ戻る。脱落した人は次のラウンドに出られない。
- 勝敗: 最後の夜が終わって1人でも残れば人の勝ち。途中で全員脱落したら鬼の勝ち。

## 鬼の待機ルーム
- 鬼が ONI_SPLIT_MIN 匹以上: 各自が部屋を選ぶ(定員 ONI_ROOM_CAP)。未満: 全員の投票で1部屋(同数ならランダム)。
- 鬼に見えるのは部屋の名前と地形の特徴だけ。人数・建築状況は見えない。
- 種類・部屋・強化は毎夜選び直せる(種類は前回のまま残る)。

## 夜
- 鬼は選んだ部屋の扉の前に立ち、ONI_ENTER_DELAY 秒後に入ってくる。その瞬間、その部屋にいる人の画面にだけ警告音と「⚠ 鬼が来た！」。
- 人には鬼がどの部屋を選んだかは知らされない(テロップも出ない。他の部屋の鬼は画面にもミニマップにも出ない)。鬼のプレイヤーには「◯◯の部屋を選んだ」と出る。
- 鬼は自分の部屋の中の人と建物しか見えない(他の部屋の建物は非表示、ミニマップも暗く隠す)。
- 鬼のいる部屋の人と鬼は、その部屋から出られない。
- 鬼のいない部屋の人は、夜開始から RESCUE_OPEN 秒後に通路が開き、救援に行ける。救援に来た人も鬼にタッチされれば凍結する。
- 救援ランプ: 部屋で人が凍結すると、その部屋の扉の上のランプが赤く点滅する(霧の影響なし・全部屋から見える・ミニマップにも赤丸)。凍結者がいなくなると消える。他の部屋の人にはトーストで通知。

## 仕様の食い違いについての判断
- 「ゲーム開始時に均等に配置」と「部屋選択画面」: 開始時も部屋選択画面を出し、選ばなかった人を人数の少ない部屋に入れることで均等になるようにした。
- 「鬼は各部屋の人数だけ見える」と「人数・建築状況は見えない」: 後の方(見えない)を採用。
- 「鬼が◯◯の部屋を選んだとテロップ」と「人には知らされない」: テロップは鬼のプレイヤーにだけ出す。人には「鬼がどこかの部屋にやってくる…」と出す。

# 視点・マイクラ式建築・宇宙人(UFO)

## 定数
BUILD_REACH=4 / BEAM_COOLDOWN=10 / UFO_MIN_HEIGHT=4 / UFO_MAX_HEIGHT=10(ほか BEAM_RADIUS=1.3, UFO_STUN=3, MAX_STACK=10)

## 視点
- ミニマップ左の「👁」ボタン(PCはVキー)で 主観(一人称)⇔客観(三人称)を切り替え。
- 主観: 目の高さにカメラ、自分の体は非表示。右半分スワイプで左右と上下(PCは矢印キー)。体の向きは視線に合わせる。
- 客観: 斜め後ろ上から追従。右半分スワイプは左右のみ。照準が3マスほど先の足元を指すように少し前を見る。
- どちらでも画面中央に十字の照準。

## 建築(マイクラ式)
- 世界をボクセル(1マス=1ブロック)で管理。壁は縦2マス、屋根は薄い板(足場の上でも下でも置ける)。
- 照準(画面中央)のレイを飛ばし、最初に当たったブロック/地面/地形の手前のマスにプレビュー。目から BUILD_REACH マス以内のみ。
- 置ける条件: 地面の上、または上下左右前後のどこかがブロックにくっついていること。キャラや箱と重なる場所・通路には置けない。
- 「建てる」で確定、長押しで 足場→壁→屋根 を切り替え。置けないときはプレビューが赤く、理由をHUDに表示。
- ブロックが壊れたら、地面までつながっていないブロックをまとめて落下させて消す(根元を壊すと上が全部崩れる)。
- 橋の下や張り出した屋根の下は歩ける(頭上の高さが足りないと通れない)。ジャンプで頭をぶつける。
- 旧仕様の「向いている方向の1マス先に置く」は削除。

## 宇宙人(UFO)
- 鬼の種類に「🛸 宇宙人」を追加。UFOで空中を移動(遅め)。壁・足場・木を飛び越える(部屋からは出られない)。
- 鬼プレイヤーは「▲上昇」「▼下降」(PCはR/F)で高さ4〜10を操作。攻撃ボタンが「ビーム」になる。
- ビーム: UFOの真下(半径1.3)にいる人を吸い上げてUFOに閉じ込める。クールタイム10秒。
  - 頭上(UFOより下)にブロックがある人には届かない(「屋根でガード!」)。
  - 閉じ込められた人は凍結扱い(凍結回数+1、3回目の次は即脱落)。FREEZE_LIMIT秒で脱落。触れての解凍はできない。
- 人がUFOを叩くと、閉じ込めた人を全員解放し、UFOは3秒操作不能。
  - 叩けるのはUFOの底が自分の頭から1.2以内のとき。地面からジャンプすれば最低高度(4)のUFOに届く。高度を上げたUFOには足場に登って叩く。
- CPUのUFO: 屋根の下にいない人の真上へ飛んでビーム。高い所にいる人には高めに飛ぶ。
- CPUの人: 仲間を閉じ込めたUFOのビームが充電中なら、下にもぐってジャンプして叩く。
- 旧2D版の「壁を1回すり抜け」「ビームで地面に下ろす」は3D版には入れていない。

## 追加: UFOの破壊ビーム / CPUの屋根づくり
- UFOのビームは2種類。
  - タップ: 吸い上げビーム(真下の、屋根の下にいない人を吸い上げる)。クールタイム BEAM_COOLDOWN は吸い上げたときだけ消費。
  - 押し続ける(PCはJ長押し): 破壊ビーム。UFOの真下で一番上のブロックに当て続けると、1マス1秒(BEAM_BREAK_TIME)で壊れる。壁は2マスなので2秒。オレンジ色の光線とHUDの「破壊中 ◯%」で表示。
  - 壊したブロックで支えを失ったブロックはまとめて落ちる。
- CPUのUFO: 屋根の下にいない人がいればその真上へ行って吸い上げ。全員が屋根の下なら、その屋根の真上に行って破壊ビームで壊してから吸い上げる。
- CPUの人の建築:
  - 階段(2〜3段)のてっぺんの横に柱を立て、柱にくっつけて頭上に屋根をかける(木材が足りるとき)。肉食動物にもUFOにも強い避難場所。
  - 石があれば「壁+屋根」の小屋を地面に作る(壁の横の頭上に屋根)。
  - 夜、UFOが近づくと屋根の下(頭上にブロックがあり、頭がつかえないマス)へ逃げこむ。

## 追加: 鬼の速さ・ライト・ビームボタン
- 鬼全体の移動速度を ONI_SPEED_MUL=1.25 倍に(肉食動物 6.25 / モンスター 4.1 / UFO 3.5。人は 4.2)。
- UFOは常に真下へサーチライト(光の円錐+地面の光の輪)を照らす。
- 肉食動物・モンスターは目から前方へライト(光の円錐)が出る。
- 光の帯は霧の影響を受けないので、夜でも遠くから鬼の位置がわかる。実際に地面を照らすスポットライトは、軽さのため見えている鬼のうち近い2匹分だけ。
- UFOのビームはボタンを押している間ずっと出る(空振り=水色、建物を壊している=オレンジ、吸い上げた瞬間=緑)。

## 変更: UFOの凍結ビーム(連射・斜め下) / 鬼をさらに速く
- 鬼全体の速度倍率 ONI_SPEED_MUL を 1.5 に(肉食動物 7.5 / モンスター 5.0 / UFO 4.2。人は 4.2)。
- UFOのビームは「吸い込み」をやめ、「凍結ビーム」に変更。
  - ボタンを押している間、BEAM_RATE(0.15秒)ごとに連射。真下ではなく斜め下へ飛ぶ(下向きが足りない方向は BEAM_MIN_DOWN で斜め下に補正)。届く距離は BEAM_RANGE(16)。
  - プレイヤーは照準(画面中央)の先に向けて撃つ。客観視点ではUFOのときだけカメラを低めにして、UFOの斜め前下を照準するようにした(光線がUFOから照準へ伸びて見える)。
  - 人に当たると通常の凍結(仲間が触れれば解凍できる)。凍結時間延長の強化も有効。
  - 建物に当たると削れて、1マスあたり合計1秒分当てると壊れる(壁は2秒)。壁や屋根はビームを防ぐ盾になる。
  - 人がUFOを叩くと3秒操作不能(閉じ込めがなくなったので解放処理は削除)。
- CPUのUFO: 狙った人から3.5マスほど離れた斜め上を回りこみながら、人に向けて連射する。

## 変更: 自動ロックオン / 鬼はすべてを壊せる / 攻撃モーション追加
- UFOの凍結ビームは自動ロックオン。射程内で斜め下にいる人のうち、さえぎる物がない一番近い人を狙う(いなければ照準の方向)。ロックした人に赤い「LOCK」枠を表示。
- 鬼の攻撃は建物だけでなく地形も壊せる(柵と部屋の仕切り・ゲートは除く)。
  - HP: 木4 / 岩8 / タンク6 / 工場の壁8 / 小屋20(9マスで1つ)。肉食動物は1、モンスターは5ダメージ。ビームは毎秒4(BEAM_DPS)。
  - 壊した地形はミニマップからも消える。CPUの鬼は、道がふさがっていれば地形も壊して進む。
  - 屋根のHPを5→4に(ビーム1秒で1マス壊れるように)。

  - 肉食動物: かみつき(前に突進) / ひっかき(体をひねる) / とびかかり(跳ぶ)。白い斬撃エフェクト付き。
  - モンスター: たたきつけ(両腕を振り上げて振り下ろす・衝撃波) / なぎはらい(腕を横に振る) / 踏みつけ(跳んで着地・衝撃波)。腕は肩を支点に動く。

## 変更: 鬼の攻撃ルール / モデル / 走るアニメ / 土煙
### 鬼の攻撃

## 掘る(地下通路)
- 「掘る」ボタン(PCは G)。UFO以外の全員が使える(鬼は鬼ごっこ中のみ)。
- 地表で掘る → 正面1マスに **穴**。中に入ると地下(床 `UG_FLOOR`=-3.1)へ落ちる。
- 地中で掘る → 正面1マスが **地下通路** になる。掘り進めるほど通路が伸びる。
- 穴の底でジャンプすると地上へ出られる。
- 建物・木・岩・通路のマスには穴を掘れない。穴の上には建築できない(地下通路の上にはできる)。
- 地中では強制的に主観視点。画面上部の矢印がいちばん近い穴(出口)の方向と距離を示す。穴の真下では「ジャンプで地上へ」と表示。
- 地中の人は鬼から見えない(画面・ミニマップ・CPUの狙い)。鬼も地中を掘り進み、`FIND_DIST`=3 マス以内に近づけば見つけられる。
- 地中の人には、土ごしに鬼の位置(👹 距離)が表示される。
- 鬼は人が掘った穴・通路をそのまま通れる。
- UFOのビーム・ロックオンは地中に届かない。
- CPUの人: 昼に「穴+通路3マス」の隠れ家を掘ることがある。鬼が来ると近くの穴へ潜り、地中の鬼が近づくと遠い穴から地上へ逃げる。
- CPUの鬼: 地上に見える人がいなければ、隠れた人の近くの穴へ入るか真上を掘り、地中を掘り進んで探す。
- 定数: `UG_FLOOR` / `UG_CEIL` / `DIG_COOLDOWN`(0.4) / `DIG_COOLDOWN_ONI`(0.8) / `FIND_DIST`。
- **穴を埋める**: 地中にいると「建てる」ボタンが「穴を埋める」になる。自分が掘った穴の真下か手前で押すと、木2か石2(石を優先)で穴をふさぐ。地上から穴は消え、下の通路は残る。
- **上に掘る**: 地中で正面がもう掘ってある(または掘れない)ときに「掘る」と、真上に穴が開いて出口になる(上に建物があるとダメ)。
- CPUの人は、地上の鬼が近いと自分の穴をふさいで隠れ、地中の鬼が迫って出口がなければ真上を掘って逃げる。
- 定数: `FILL_COST`(2)。
- **進行方向の矢印**: 地中では目の前に水色の矢印が出て、進んでいる方向(止まっているときは向いている方向)を示す。上部の黄色い矢印は出口(穴)の方向。
- **地中は制限なく掘れる**: 地上の木・岩・通路の下も掘り進められる(フィールドの外だけは不可)。穴(地表)を開けるときの制限はそのまま。
